## 🚀 Kurulum

### Gereksinimler
- Node.js 18+
- Git

### Hızlı Başlangıç

```bash
# 1. Klonla
git clone https://github.com/yourusername/jukeboxd.git
cd jukeboxd

# 2. Frontend kurulumu
npm install

# 3. Backend kurulumu
cd server && npm install && cd ..

# 4. Başlat (2 terminal)
# Terminal 1: Backend
cd server && npm run dev

# Terminal 2: Frontend
npm run dev
```

🌐 Uygulama: `http://localhost:5173`

## ⚙️ Yapılandırma

### Frontend (`.env`)
```env
VITE_API_URL=http://localhost:3001
```

### Backend (`server/.env`)
```env
JWT_SECRET=your_super_secret_key
PORT=3001
SPOTIFY_CLIENT_ID=your_spotify_client_id
SPOTIFY_CLIENT_SECRET=your_spotify_client_secret
ALLOWED_ORIGINS=http://localhost:5173
NODE_ENV=development
```

## 📚 API Endpoints

### 🔐 Authentication
| Method | Endpoint | Açıklama |
|--------|----------|----------|
| POST | `/api/auth/register` | Kayıt ol |
| POST | `/api/auth/login` | Giriş yap |
| GET | `/api/auth/me` | Token doğrulama |

### 👥 Users
| Method | Endpoint | Açıklama |
|--------|----------|----------|
| GET | `/api/users/:id` | Profil |
| PUT | `/api/users/profile` | Profil güncelle |
| POST | `/api/users/:id/follow` | Takip et |
| PUT | `/api/users/digest-settings` | Özet ayarları |

### 🎁 Referrals
| Method | Endpoint | Açıklama |
|--------|----------|----------|
| GET | `/api/referrals/code` | Referral kodu al |
| POST | `/api/referrals/apply` | Kod kullan |
| GET | `/api/referrals/stats` | İstatistikler |

### 🏆 Badges
| Method | Endpoint | Açıklama |
|--------|----------|----------|
| GET | `/api/badges` | Kullanıcı rozetleri |
| POST | `/api/badges/check` | Rozet kontrolü |
| GET | `/api/badges/all` | Tüm rozetler |

### 🛡️ Admin
| Method | Endpoint | Açıklama |
|--------|----------|----------|
| GET | `/api/admin/stats` | Dashboard |
| GET | `/api/admin/users` | Kullanıcılar |
| PUT | `/api/admin/email-settings` | E-posta ayarları |
| POST | `/api/admin/email-test` | Test e-posta |
